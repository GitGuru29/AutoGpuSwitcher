AutoGpuSwitcher Phase 2 Tasks
=============================

1. Install and verify the NVIDIA driver stack for the target system.
2. Confirm PRIME render offload works with commands such as:
   - nvidia-smi
   - prime-run glxinfo | grep "OpenGL renderer"
3. Define the launcher/interceptor runtime contract:
   - input executable path
   - argument forwarding
   - exit code forwarding
4. Implement the C++ launcher in interceptor/src/main.cpp.
5. Implement heavy app list lookup logic in interceptor/src/heavy_app_db.cpp.
6. Implement NVIDIA environment policy setup in interceptor/src/env_policy.cpp.
7. Make the launcher read heavy app records in the format:
   package-name|app-name|/full/path/to/binary
8. Match apps by executable path first, then by app name if needed.
9. Apply NVIDIA/PRIME environment variables only for heavy apps.
10. Exec the target application after environment setup.
11. Add logging for launcher decisions:
    - matched heavy app
    - non-heavy app
    - missing list file
12. Add CMake build instructions and verify the launcher builds cleanly.
13. Test with known heavy applications and confirm they launch on the dGPU.

AutoGpuSwitcher Phase 3 Tasks
=============================

1. Add desktop integration so GUI apps launch through AutoGpuSwitcher.
2. Define how .desktop files will be wrapped or regenerated safely.
3. Add shell integration for terminal-launched applications.
4. Add system-wide install logic for the phase 2 launcher binary.
5. Connect the launcher install path with phase 1 installed state/config.
6. Add optional systemd user service or timer support if background helpers are needed.
7. Add a command to rebuild desktop integration after package installs.
8. Add a command to rescan or repair heavy app state.
9. Add better user-facing logging and troubleshooting output.
10. Document full installation, first-run, hook deployment, and launcher integration.
11. Test end-to-end flow:
    - install app
    - hook analyzes package
    - app appears in heavy_apps.list
    - next launch uses dGPU
12. Validate gaming use cases with Steam/Proton and native games.
13. Prepare packaging/release layout for GitHub and future Arch packaging.
